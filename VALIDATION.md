Last Updated: 2026-10-13

Среда: macOS, bb 0.46.0 (SDK 0.6.37, npm в составе bb 11.16.0), Node.js 25.2.1,
npm 11.6.2. Итоги выпусков 0.3.0, 0.2.0 и 0.1.0 — ниже.

в 0.3.0–0.3.2. Строки про File Manager и инструкцию для телефона — из проверок 0.3.1 и 0.3.2.

## Итоги выпуска 0.2.0

Код пяти плагинов совпадал с рабочими копиями автора (кроме README, версий и обезличенных
файлов). Установка как у bb из Git по тегу `v0.2.0` — пять плагинов собраны; `npm ci`, тесты
(28, 10, 10, 86, 366) и проверка типов Explorer_vibecom и Terminal_vibecom прошли. Содержимое
`files-editor/vendor/*.tgz` совпадало с `src/` просмотрщиков. Тема побайтово совпадала с
рабочей темой автора; `bb theme show atom-one_vibecom` находил её по новому id.

## Итоги выпуска 0.1.0

На BB 0.44.0 три плагина работали у автора (`running`), тема `atom-one`
была активна. Чистая сборка и тесты проходили на BB 0.45.0. Проверка
Git-источника на локальном тестовом репозитории с тегом `v0.1.0` прошла.

## Не проверено

- Установка в bb из публичного URL: не выполнялась — она заменила бы плагины автора.
- Установка плагинов в bb из папки распакованного комплекта: у автора они стоят из
  рабочего репозитория, а отдельного чистого профиля у CLI нет.
- Тема на bb 0.46.0 в активном режиме и её поправка кнопок режимов разрешений.
- Windows (автор проверял комплект на bb 0.45.0, маршрут не уточнён), Linux-сервер,
  физический телефон, подключение Connect.
- Визуальная точность Office_vibecom и просмотра документов в Explorer_vibecom
  на реальных файлах: тесты проверяют чтение файлов и состав пакетов.
- `npm run test:mobile` у Terminal_vibecom: он шлёт команды в живые терминалы bb.
- PDF-версия инструкции в этом выпуске не собиралась.
- Работа кода на bb 0.43–0.45 и на версиях новее 0.46.0.
