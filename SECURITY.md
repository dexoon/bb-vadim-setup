# Безопасность

Плагины bb выполняются с полным доверием: серверная часть плагина имеет доступ к файлам
рабочей копии и запускает процессы, без песочницы. Перед установкой читайте исходники —
они открыты в этом репозитории. Комплект не содержит ключей и токенов:
`models/pi/auth.example.json` — шаблон, свои ключи вводит пользователь.

## Переделки чужих плагинов

`files-editor` (Explorer_vibecom) — переделка Files editor abdoutelb, `floating-terminal`
(Terminal_vibecom) — переделка Floating Terminal vburojevic. Исправления из оригиналов
переносятся вручную через `scripts/sync-plugins.py` и приходят с задержкой: уязвимость
в оригинале — не обязательно уязвимость здесь, и наоборот. Подробности — в README и
LICENSE каждого плагина и в `THIRD_PARTY_NOTICES.md`.

## Как сообщить

Уязвимость — через «Report a vulnerability» на вкладке Security репозитория: описание,
шаги воспроизведения, затронутые версии. Пожалуйста, не публикуйте подробности, пока
не выйдет исправление. Всё остальное — обычные issue.

О уязвимостях в самом bb сообщайте проекту bb, а не сюда.
