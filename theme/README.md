# Тема atom-one_vibecom

Last Updated: 2026-10-14

Скопируйте всю папку atom-one_vibecom в каталог из bb theme dir, затем
bb theme set atom-one_vibecom. Три исходных файла: theme.css, theme.json,
one-dark.json. Пользовательский CSS включает цвета интерфейса и поправку
доступности разрешений в composer BB 0.44.

С выпуска 0.3.6 тёмный режим контрастнее — как тёмная тема Telegram Desktop
(Tinted), оттенки остались от Atom One: основной текст ≈#edf0f6 (контраст 14,9:1,
было 8:1), список тредов #0f1013, рамки и выделения подстроены под те же значения.
Светлый режим не менялся. Обновить: скопируйте новую папку поверх прежней и
выполните bb theme set atom-one_vibecom.

До выпуска 0.2.0 тема называлась atom-one. Если у вас стоит atom-one, скопируйте
новую папку, выполните bb theme set atom-one_vibecom и после проверки удалите
старую папку atom-one.

Основа подсветки: Atom One Dark, https://github.com/akamud/vscode-theme-onedark.
