# Тема atom-one_vibecom

Last Updated: 2026-10-11

Скопируйте всю папку atom-one_vibecom в каталог из bb theme dir, затем
bb theme set atom-one_vibecom. Три исходных файла: theme.css, theme.json,
one-dark.json. Пользовательский CSS включает цвета интерфейса и поправку
доступности разрешений в composer BB 0.44.

До выпуска 0.2.0 тема называлась atom-one; файлы не изменились. Если у вас
стоит atom-one, скопируйте новую папку, выполните bb theme set atom-one_vibecom
и после проверки удалите старую папку atom-one.

Основа подсветки: Atom One Dark, https://github.com/akamud/vscode-theme-onedark.
Лицензия MIT сохранена в atom-one_vibecom/LICENSE-One-Dark.txt.
