# Проверка Markdown_vibecom

## Задача

Замените слово «готово» в таблице, сохраните файл и проверьте diff.

| Компонент | Статус |
|---|---|
| Тема | готово |
| Markdown | готово |

## Порядок

1. Откройте «Правка».
2. Измените одну строку.
3. Сохраните и вернитесь к просмотру.

```text
bb theme show
bb plugin list
```

Для проверки папки попросите агента дать Markdown-ссылку с абсолютным путём
к существующей папке внутри домашнего каталога вашего сервера.
